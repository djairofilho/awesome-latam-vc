## Perfil del programa

GitHub for Startups ofrece a empresas elegibles créditos de plataforma,
incorporación, sesiones abiertas y prácticas técnicas.

## Elegibilidad y solicitud

Las candidatas deben estar vinculadas a un socio aprobado, tener financiación
externa hasta Series B y ser nuevas en los planes y créditos de GitHub elegibles.
