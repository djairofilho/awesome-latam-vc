## Perfil del programa

Google for Startups Cloud Program combina créditos de Google Cloud y Firebase
con soporte de producto, mentores y especialistas del sector.

## Elegibilidad y solicitud

El programa publica rutas Start y Scale para empresas jóvenes, incluidas
startups sin inversión y startups respaldadas por capital externo.
