# AWS Activate

- **Sitio web:** https://aws.amazon.com/startups/credits/?lang=en-US
- **Operador:** Amazon Web Services
- **Tipo de programa:** Programa de apoyo a startups
- **Abierto a fundadores externos:** Sí
- **Estado de actividad:** Activo
- **Estado de postulación:** Abierto
- **Formato del programa:** Programa continuo de créditos de nube y apoyo a startups
- **Duración:** No divulgada públicamente
- **Etapa:** De pre-seed a pre-Series B
- **Capital ofrecido:** Hasta USD 200,000 en créditos de AWS
- **Instrumento:** Créditos de nube en especie
- **Participación accionaria:** No divulgada públicamente
- **Geografía:** Global
- **Postular:** https://startups.aws.com/join?destination=%2Fcredits%2Fapply
- **Alias:** Ninguno publicado
- **Vehículo de inversión:** No se identificó ningún vehículo de inversión independiente que cumpliera los criterios

## Perfil del programa

AWS Activate ofrece a startups elegibles créditos de nube, beneficios, eventos
y orientación inicial. El registro del programa es distinto de Amazon Web
Services y de cualquier vehículo de inversión.

## Elegibilidad y solicitud

Los fundadores sin inversión pueden postular directamente. Las startups
respaldadas por proveedores pueden postular con un ID de organización. La
elegibilidad publicada cubre empresas anteriores a Series B.

## Señales de actividad

Las páginas oficiales del programa y de postulación estaban activas el
2026-08-03 y describían AWS Activate como un programa global con postulaciones
abiertas.
