# Security Policy

## Supported version

The latest revision of the `main` branch and the website published from it are
supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Submit a private
[security advisory](https://github.com/djairofilho/awesome-latam-vc/security/advisories/new)
with:

- the affected page, workflow, dependency, or script;
- steps to reproduce the issue;
- its potential impact;
- any suggested mitigation, if available.

Reports about incorrect or outdated catalog information are not security
issues. Use the data correction issue form for those cases.

## Scope

Security reports may cover the static website, build scripts, automation,
published data files, or repository workflows. Third-party websites linked by
the catalog remain outside this project's security scope.
