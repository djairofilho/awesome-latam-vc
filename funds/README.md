# Venture capital funds

This directory contains organizations that invest directly in startups through
recurring venture capital vehicles or programs. See the
[main project index](../README.md) for the complete fund catalog.

## Directory structure

Fund profiles are organized by geographic base:

- country directories contain organizations based in that country;
- `regional/` contains organizations based in Latin America that explicitly
  invest across the region;
- `multi-country/` contains organizations based outside Latin America with an
  explicit investment presence in the region.

Fund type and geographic base are separate classifications. Corporate venture
capital, accelerator funds, studio funds, and co-investment vehicles follow the
same geographic rules.

## Inclusion criteria

An organization belongs in this directory only when current official sources
confirm that it invests capital directly in startups through a recurring fund,
corporate venture program, co-investment vehicle, accelerator fund, or studio
fund.

Organizations that connect founders and investors, provide acceleration without
a qualifying investment vehicle, operate funding platforms, or administer
public support programs belong in the
[related investment ecosystem](../ecosystem/README.md).
