# Programa Centelha

Programa Centelha is coordinated by Finep with state partners to help transform
innovative ideas into technology-based businesses. Applications and financial
terms are published separately for each participating state and cycle.

## Program profile

- **Official page:** https://www.finep.gov.br/apoio-e-financiamento-externa/programas-e-linhas/centelha
- **Operator:** Finep and state partners
- **Geography:** Brazil
- **Financial support:** Defined by each state call
- **Founder route:** https://www.finep.gov.br/apoio-e-financiamento-externa/programas-e-linhas/centelha
