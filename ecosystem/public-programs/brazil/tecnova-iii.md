# Tecnova III

Tecnova III is a Finep program that distributes economic grants for innovation
through selected state partners. Interested businesses must use the relevant
state call because eligibility, deadlines and award terms vary by location.

## Program profile

- **Official page:** https://www.finep.gov.br/apoio-e-financiamento-externa/programas-e-linhas/tecnova
- **Operator:** Finep and state partners
- **Geography:** Brazil
- **Financial support:** Economic grants under state calls
- **Founder route:** https://www.finep.gov.br/apoio-e-financiamento-externa/programas-e-linhas/tecnova
