## Program profile

AWS Activate provides eligible startups with cloud credits, offers, events and
onboarding. The program record is distinct from Amazon Web Services and from any
investment vehicle.

## Eligibility and application

Self-funded founders can apply directly. Provider-backed startups can apply with
an organization ID. The published eligibility covers companies before Series B.
