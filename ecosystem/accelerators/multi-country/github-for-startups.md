## Program profile

GitHub for Startups provides eligible companies with platform credits,
onboarding, office hours and technical practices.

## Eligibility and application

Applicants must be affiliated with an approved partner, have outside funding no
later than Series B and be new to the eligible GitHub plans and credits.
