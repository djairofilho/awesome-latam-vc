# Accelerators

This category covers active, structured acceleration programs that accept
startups from Latin America but do not have a qualifying recurring investment
vehicle for the main fund catalog.

Programs that make direct startup investments through a recurring accelerator
fund belong in [`funds/`](../../funds/README.md). Consultancies, coworking
spaces, communities, and events do not qualify solely because they support
startups.
