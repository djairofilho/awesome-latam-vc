# Poli Angels

Poli Angels is an angel network connected to the Polytechnic School community.
It reviews sector-agnostic early-stage startups, while each associated investor
decides independently whether to invest.

## Network profile

- **Website:** https://poliangels.com.br/
- **Stage:** Angel, pre-seed and seed
- **Geography:** Brazil
- **Submit a startup:** https://poliangels.com.br/
- **Capital source:** Individual members
