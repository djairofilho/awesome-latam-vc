# Cubo Itaú

Cubo Itaú is a Brazilian innovation hub that selects startups for a community
with companies, partners and investors. It provides matchmaking and fundraising
preparation but is not presented as a direct investment vehicle.

## Hub profile

- **Website:** https://cubo.itau/startups
- **Organization type:** Innovation hub
- **Geography:** Brazil
- **Startup access:** Selection process for validated, scalable businesses
- **Apply:** https://cubo.itau/startups-apply
- **Direct investment:** No qualifying vehicle identified
