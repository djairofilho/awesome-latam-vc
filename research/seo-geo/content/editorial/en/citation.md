# Citing Awesome LatAm VC

Cite the project with a URL, access date and a version identifier when
reproducibility matters. For a factual claim, also cite the underlying source
listed by the relevant profile. The directory citation identifies the curated
record; it does not replace the evidence behind that record.

## Preferred citation

Use this pattern for the repository:

```text
Awesome LatAm VC. Awesome LatAm VC directory. GitHub repository,
https://github.com/djairofilho/awesome-latam-vc. Accessed YYYY-MM-DD.
Commit COMMIT_SHA.
```

## Dataset citation

When citing an export, use its public URL after publication and record the
access date plus the commit or release that produced it. Do not cite a mutable
download without a version identifier when exact reproduction is required.

## Stable references

For one entity, include its name and canonical Markdown URL. Link to the file's
Git history when the change record matters. Preserve official source titles and
destinations exactly.
