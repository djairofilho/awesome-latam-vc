# Sources

Each profile carries titled source URLs and a verification date. Sources support
the nearby claim or normalized field; they do not authorize broader conclusions
about an entity. Readers can inspect the canonical Markdown and its Git history
to see the evidence available when the profile was reviewed.

## Source hierarchy

Research favors first-party material for an entity's thesis, application route,
program details and public activity. Official regulators and program owners
support claims in their respective domains. A secondary source is labeled as
such and does not become an official statement.

## How evidence is recorded

Source titles, URLs, kinds, order and intentional repetition are part of the
canonical metadata. Visible profile text keeps declared claims distinct from
observed portfolio or activity signals.

## When evidence is insufficient

The catalog uses explicit non-disclosure values when available evidence does
not support a field. It does not estimate check size, stage, focus, coverage or
activity. A missing or inaccessible source is a limitation to report, not a gap
to fill with an inference.
