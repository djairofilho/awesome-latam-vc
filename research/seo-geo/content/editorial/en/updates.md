# Updates and corrections

Awesome LatAm VC is versioned in Git. A profile's verification date records
when its cited information was checked; it is not a guarantee that every linked
offer or application remains open. Later corrections remain visible in commit
history.

## Update cycle

Catalog changes are reviewed as repository changes. New research can add,
correct or retire claims while preserving the earlier version in Git. The site
rebuilds from accepted canonical files rather than a separate database.

## Verification dates

`last_verified` belongs to an individual profile. Readers should use that date
with the cited sources when evaluating time-sensitive details. A site build
date does not replace it.

## Corrections

Report a suspected error with the profile path, disputed statement and
supporting source. A correction should change the smallest affected claim and
must not silently alter names, URLs, dates or other protected values in a
translation.
