# Cómo citar Awesome LatAm VC

Cuando la reproducibilidad sea importante, cite el proyecto con una URL, una
fecha de consulta y un identificador de versión. Para respaldar una afirmación
factual, cite también la fuente subyacente incluida en el perfil correspondiente.
La cita del directorio identifica el registro curado, pero no reemplaza la
evidencia que lo sustenta.

## Cita recomendada

Use este formato para citar el repositorio:

```text
Awesome LatAm VC. Awesome LatAm VC directory. GitHub repository,
https://github.com/djairofilho/awesome-latam-vc. Accessed YYYY-MM-DD.
Commit COMMIT_SHA.
```

## Cita del conjunto de datos

Al citar una exportación, use su URL pública una vez publicada y registre la
fecha de consulta junto con el commit o la versión que la generó. Si necesita
una reproducción exacta, no cite una descarga mutable sin un identificador de
versión.

## Referencias estables

Para citar una entidad, incluya su nombre y la URL canónica del archivo Markdown.
Enlace el historial de Git del archivo cuando sea importante consultar los
cambios. Conserve exactamente los títulos y destinos de las fuentes oficiales.
