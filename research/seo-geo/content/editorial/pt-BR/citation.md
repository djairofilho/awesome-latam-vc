# Como citar o Awesome LatAm VC

Cite o projeto com uma URL, uma data de acesso e um identificador de versão
quando a reprodutibilidade for importante. Para uma afirmação factual, cite
também a fonte subjacente listada pelo perfil correspondente. A citação do
diretório identifica o registro curado; ela não substitui as evidências por
trás desse registro.

## Citação recomendada

Use este padrão para o repositório:

```text
Awesome LatAm VC. Awesome LatAm VC directory. GitHub repository,
https://github.com/djairofilho/awesome-latam-vc. Accessed YYYY-MM-DD.
Commit COMMIT_SHA.
```

## Citação do conjunto de dados

Ao citar uma exportação, use sua URL pública após a publicação e registre a
data de acesso, além do commit ou release que a produziu. Não cite um download
mutável sem identificador de versão quando a reprodução exata for necessária.

## Referências estáveis

Para uma entidade, inclua seu nome e a URL do Markdown canônico. Quando o
registro de alterações for relevante, vincule o histórico do arquivo no Git.
Preserve exatamente os títulos e destinos das fontes oficiais.
